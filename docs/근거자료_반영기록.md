앱의 「데이터·사업가이드 → 법적 근거」 탭에도 같은 내용이 표시됩니다 (`src/lib/근거자료_반영이력.ts`).

- **원문 확인**: 제공 문서에서 직접 확인한 내용
- **플랫폼 가정**: 원문에 없어 플랫폼이 정한 값 (화면에 '플랫폼 가정'으로 표시)

### 남은 플랫폼 가정 (원문에 없음)
- 적용현황 미달 시 부분점수 부여 방식
- 질환별 적용(10점) = (적용률 + 완료율)/2 비례 — 원문은 산출 항목만 제시(시범 지표)
- 관리율(5점) 비례, 모니터링(15점) 보고 시 만점
- 프리셋 병상수·포괄수가 총액 (예시값 — 실제 청구 실적 입력 필요)
- CP ROI 가동률 80%·마진율 22%·이탈 방지 반영비율 15%
- 인천의료원 백령병원(시범기관)은 프리셋에 없음
