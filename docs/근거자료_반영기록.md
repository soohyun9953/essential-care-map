### 앱에서 바뀐 것
| 화면/파일 | 이전 | 이후 |
|---|---|---|
| 신포괄 시뮬레이터 가산율 | 점수 구간표 (90점↑ 1.0%, 80점↑ 0.8%, 70점↑ 0.6%, 60점↑ 0.4%) — **원문에 없음** | 1.0% × 점수/100 (비례방식) |
| 가산 금액 기준 | 연간 신포괄 진료비 × 가산율 | 포괄수가 총액 × 가산율 (지침 35쪽) |
| 운영평가 등급 | A~D (90·80·70점 기준) — **원문에 없음** | 제거 (점수만 산출) |
| 개선 처방 예상 추가재정 | 진료비 × 0.1~0.3% 임의 비율 | 점수 증가분 × 1.0% × 포괄수가 |
| 공공병원 프리셋 | 영주적십자병원 포함, 포천·강릉·삼척 '병원급', 제주의료원 '종합병원' | 시범기관 명단 기준: 영주적십자 제외, 종별 정정 |
| 안내 모달·가이드 | "관리율 85% 이상", "원문 미확인" 표기 | 원문 문구로 교체 |
| CP ROI | 가동률 80%·마진율 22%·15%가 코드에 숫자로만 존재 | `ROI_가정값`으로 분리, 화면에 '플랫폼 가정값' 표시 |
| 지침 코퍼스 | CHUNK-EVAL-02 "7대 질환 CP 적용률 75% 가점" (원문 미확인) | 원문 확인 내용으로 교체, CHUNK-SINPO-01 추가 |

### 남은 플랫폼 가정 (원문에 없음)
- 적용현황 미달 시 부분점수 부여 방식
- 질환별 적용(10점) = (적용률 + 완료율)/2 비례 — 원문은 산출 항목만 제시(시범 지표)
- 관리율(5점) 비례, 모니터링(15점) 보고 시 만점
- 프리셋 병상수·포괄수가 총액 (예시값 — 실제 청구 실적 입력 필요)
- CP ROI 가동률 80%·마진율 22%·이탈 방지 반영비율 15%
- 인천의료원 백령병원(시범기관)은 프리셋에 없음
